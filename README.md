# Library Express

A Java backend application for library management.

## Features

- Book management
- Client management
- Loan management
- Business rule validation
- Exception handling

## Tech Stack

- Java
- Maven

## Project Structure

```
domain/
infrastructure/
```

## Getting Started

```bash
git clone https://github.com/silverioTenor/challenge-02--library_express.git

cd challenge-02--library_express

mvn clean install

mvn exec:java
```
