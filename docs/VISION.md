# Product Vision (Long Term) — Retired

This document is retired. It previously described an aspirational, non-executable long-term vision for Library Express (a self-service platform, a third-party catalog marketplace, payments, a book club subscription, audiobooks/video, and an eventual microservices/event-driven evolution).

None of that vision ever generated epics directly — it only informed low-cost architectural choices in the active roadmap, such as the domain/application/infrastructure layering already in place. That benefit has already been captured and requires no further action.

Library Express's scope is now bounded to what is tracked in [`BACKLOG.md`](./BACKLOG.md), ending at Epic E10 (Notifications). The expansions this document used to describe are not planned for this project.

Full rationale: [`docs/adr/0001-keep-library-express-framework-free.md`](./adr/0001-keep-library-express-framework-free.md).
